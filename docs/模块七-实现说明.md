## 一、三层分离架构（踩坑 #4 的正面回答）

| 层 | 承载 | 存储 | 代码 |
|---|---|---|---|
| **记忆** | 发生过什么 | `memory_events` append-only（(event, time) 二元组，只增不删） | `api/app/memory/store.py` |
| **状态** | 现在处于什么 | 假设 FSM：`proposed→active→supported/refuted→superseded`（合法转移表强制，转移历史 append-only 记入 meta.transitions[]） | `store.HYPOTHESIS_TRANSITIONS` |
| **任务** | 本轮怎么执行 | LangGraph 五客栈路由 + checkpoint（v1 既有，本就是 FSM 约束） | `api/app/agents/` |

时间图谱（THEANINE）：`entities` 实体消解 + `memory_edges` 因果/时序边（UNIQUE 三元组 +
UPSERT 确认计数；关系翻转/LLM 升级旧边标 superseded 保留演化史）。检索（Generative
Agents 三信号 min-max 等权相加 × FadeMem 强度乘子 × timeparse 时间窗 × 多跳 BFS）+
「当前不为真」降权（superseded/refuted ×0.3，历史按时间窗仍可召回）。

## 二、理论依据与诚实边界（§七.5 声明）

1. **三层分离**：见上表；记忆与状态不分家是 RAG 式记忆的头号通病（踩坑 #4）。
2. **FadeMem 为 arXiv 预印本**（非同行评审定稿）：引用时如实标注；参数（β=0.8/1.2、
   μ、θ=0.7/0.3）全部经 `config.py` 暴露为 env 可覆盖，P2 已跑 3×3 网格消融——小语料
   上 top5 边界不敏感（如实报告），机制生效由 top5 平均强度单调性证明（r7 报告）。
3. **ATLAS 仅借思想、非隐层干预**：三锚 embedding 漂移指标不可行（黑盒 API）；r8 落地
   裁剪预案 = **文字提示降级口径**（`drift.drift_hint`：近期与更早假设/决定的主题词面
   重叠度 <15% → 简报尾部提示，前端渲染时明确标注"借思想，非隐层干预"）。
4. **memory_save 白名单边界**：agent 受控自写工具仅 {reader, compare, writer, graph}
   可调（viz 出图场景无记忆需求）；**不进 GENERAL_DISABLED_TOOLS**——写记忆不是证据
   源，双模式均可用；只写事件（source=agent），消解/建边/衰减由巩固 worker 异步补；
   与轮末抽取同轮同内容去重。
5. **"70% 真实世界事实带时间约束" 不引用**：该数字出自厂商博客（supermemory.ai），
   无原始研究出处——全部文档与答辩口径不使用该数字，改以本仓库可复现的评测说话
   （r7 报告：矛盾检出 R 100% vs 朴素词面基线 0%）。

另：Memory-T1 为 RL 方案（5 周单人不可训）→ 降级为「粗筛 + LLM judge 时间一致性重排」
两段式，RL 标注 future work；ChronoMem 多模态时间记忆本项目无需求，不采纳。

## 三、手动修正（append-only 语义，MemGPT self-editing 人工版）

`PATCH /api/memory/events/{id}`：
- **content 修正不原地改**：新事件（source=manual，meta.corrected_from 指向旧 id）+
  旧事件 superseded——天然审计链；终态事件被修正 → 新事件回 active 重新判定（如实）；
- **status 修正**走 FSM 合法转移表（仅 hypothesis，非法转移 400）。

## 四、巩固 worker 与漂移提示

`worker.py`（daemon 线程，`memory_worker_interval_s` 默认 600s、≤0 关闭）：强度重算 +
滞回层迁移 / 假设 FSM 复核（proposed→active、同主题 superseded；**不代行终态判定**）/
简报缓存预热。ATLAS 漂移 = 简报 `drift_hint` 文字提示（见上）。

## 五、运行与复现

```bash
# 生成 30 会话演示库 + 半人工金标（含 §七.1 简报自检）

    --out docs/acceptance/round9-20261121-r7 --force

python api/scripts/eval_memory.py --data-dir data/seed_mem \
    --gold docs/acceptance/round9-20261121-r7/seed_gold.json \
    --out docs/acceptance/round9-20261121-r7 [--judge]
```

r7 实测结论（模拟语料 + 半人工金标，数字真实）：假设召回 100%（5/5 verdict 精确匹配）；
矛盾检出 P=R=100%（朴素词面基线 R=0%）；陈旧判断 hit@5=100%、时间窗查询 avoid 泄漏
0%、无窗查询 50%（如实保留，时间窗为推荐交互）；FadeMem 小语料参数不敏感（如实标注）。
**金标 status=pending：20% 抽检清单待人工签署后置 passed**（seed_review_sample.md）。
