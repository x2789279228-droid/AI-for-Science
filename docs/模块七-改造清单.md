## 一、总原则：删什么 · 换什么 · 加什么

### 删除：**零模块删除**
六模块 + 健康中心是赛题闭环，前后端全部保留。仅两处「策略退役」（不是删模块，是换内部做法）：
1. **记忆检索侧**的「纯语义 top-k」打分 → 三信号 + 时间窗 + 强度打分（**DocIR 文献检索完全不动**）；
2. **「会话 = 全部上下文」**的隐式状态 → 显式三层分离（记忆=事件流 / 状态=假设 FSM / 任务=LangGraph 不动）。`chat_threads` 保留为溯源账本。
   论述口径：v1 的 LangGraph 五客栈路由（Router→Planner→Executor→Verifier→Responder 合法转移图）**本身就是任务层 FSM 约束**，v2 新增的是**研究假设层** FSM——不是漏了任务层，而是两层边界本来就该分清（踩坑 #4）。

## 二、设计细节确认（v2.1 新增——原方案 12 处留白，逐项写死）

### 2.1 三层边界
| 层 | 承载 | 存储 | 备注 |
|---|---|---|---|
| 记忆 | 发生过什么 | `memory_events` append-only | (event, time) 二元组，只增不删 |
| 状态 | 现在处于什么阶段 | `memory_events.kind=hypothesis` 的 status 字段（FSM 合法转移表约束） | 状态是记忆的投影，不是第二套存储 |
| 任务 | 本轮怎么执行 | LangGraph 五客栈 + checkpoint（v1 不动） | 已是 FSM 约束，论述见 §一 |

### 2.2 假设 FSM：状态定义与转移触发（原空白）
- **proposed**：抽取/agent 写入 hypothesis 事件时的初始态；
- **active**：worker 复核发现首条同主题 experiment_result 记忆或 tracked_items 新条目时转移（触发器 = 周期复核，不是抽取同步做）；
- **supported / refuted**：briefing judge 或 worker 复核给出判定，`verdict_source` ∈ {judge, evidence, manual}，判定依据记入 `evidence_json`；
- **superseded**：同主题（实体消解后）新假设 proposed 时，旧假设由 worker 标 superseded；
- **非法转移**（如 refuted→active、supported→proposed）：store 层合法转移表直接拒绝——API 链路返回 400 + `guardrail` 提示；后台 worker 链路 `log.warning` + 拒绝记录写入该事件的 `evidence_json`（**不落 qa_logs**，那是问答链路审计表）；转移历史 append-only：每次转移在 `evidence_json.transitions[]` 追加 `{from, to, at, why, verdict_source}`。

### 2.3 FadeMem 参数与方向（原只写数值）
- 公式：`v_i(t) = v_i(0) · exp(−λ_i · (t−τ_i)^β_i)`，`λ_i = λ_base · exp(−μ · I_i(t))`；
- **强度初值**：`v_i(0) = importance / 10`（LLM 1-10 分 → 0.1~1.0）；
- **I_i(t)**：P0 用静态 `importance/10`；访问动态加成（access_count 加权）作为 P2 消融项再定；
- **层迁移方向**：`v ≥ θ_promote(0.7)` → 迁入 LML（β=0.8 慢衰减）；`v ≤ θ_demote(0.3)` → 迁入 SML（β=1.2 快衰减）；(0.3, 0.7) 区间保持原层（滞回防抖）；
- **λ_base 自标定**：以「I=0 时 LML 半衰期 ≈ 11.25 天」为初始锚点（`λ_base = ln2 / 11.25d`），P2 网格消融（λ_base × β × θ 三维）后定稿——不照搬论文参数（踩坑 #2）；
- **作用域**：强度只作检索排序乘子（`score × v(t)`），永不物理删除；`t_valid_to` 到期只是「当前不为真」，历史仍可按时间窗检索（THEANINE「历史承载演化逻辑」的前提）。

### 2.4 时间约定（踩坑 #1）
- DB 存 **UTC epoch（REAL）**，API 层输出 **ISO 8601**（带 +08:00 偏移）；
- timeparse 以**本地时区（Asia/Shanghai）**解析「上周 / 上季度 / 三个月前 / last month」，输出 UTC 区间；
- 所有时间戳 server-side 生成，不接受客户端传入时间。

### 2.5 memory_edges 约束修正（v2.0 的 UNIQUE 与演化语义冲突）
- 保留 `UNIQUE(src,dst,relation)`，写入走 **UPSERT**：同三元组再次确认时 `confirm_count += 1`、`ts` 更新、**保留最早 `t_valid_from`**（新增 `confirm_count` 列，确认次数本身是证据强度信号）；
- **关系翻转不 UPSERT**（如 supports→refutes）：旧边标 `superseded` + 新边插入，保留演化史——与事件流 append-only 同一哲学。

### 2.6 手动修正 = append-only（v2.0 的 PATCH 原地改与 append-only 冲突）
- `PATCH /api/memory/{id}` **不原地改 content**：生成新记忆事件（`source=manual`，`evidence_json.corrected_from` 指向旧 id）+ 旧事件标 superseded；
- 天然审计链，前端时间线展示修正链——同时呼应 MemGPT self-editing（人工版）。

### 2.7 memory_brief SSE 时序
- 路由在 **`meta` 事件之后、runner 线程首事件（retrieval）之前**直发，读 worker 预生成的**缓存简报**（零 LLM 调用，首字延迟零增加）；
- worker 未就绪 / 新用户无记忆：发 `memory_brief: {empty:true}`，前端不渲染简报卡；
- `use_memory=false`（ChatBody 新字段，默认 true）：整个 chat 流不下发该事件、responder 不注入时间线。

### 2.8 抽取钩子精确位置（时序敏感）
- 挂在 `run_stream` 收尾序列 **`tee.put(done)` 之后**起 daemon 线程（`finish_thread → _push_success(defer_done) → _save_trace → done` 的回放竞态时序不被打乱）；
- 抽取输入：本轮 Q + A + claims（含 `[E#] → paper_id/chunk/page/bbox` 映射）→ **每条 M 类事件可回指当轮 E# 证据**，构成「M#↔E# 同源双链」（答辩演示关键）。

### 2.9 [M#] 编号空间与校验
- 独立正则 `[M(\d+)]`（对齐现有 `CIT = r"\[E(\d+)\]"`）；注入时间线的记忆块**动态编号 M1..Mn**（与 Evidence Pack 同哲学）；
- 校验：无效 [M#] 剔除 + guardrail 记 `invalid_memory_citation`（仿 `invalid_citation:E{n}`）；L2 引文覆盖率校验对 M# **不适用**（记忆不是论文证据，只做 L1 存在性校验）；
- **回放数据链**：`memory_events(conversation_id, turn)` → `thread_id = f"{conversation_id}:{turn}"`（冒号分隔）→ `GET /api/qa/{trace_id}` 事件账本 → 前端复用 `loadConversation()` 的还原逻辑（claims/anchors/思维链合并）。

### 2.10 embedding 与降级路径
- 记忆向量**复用 indexing.py 同一管线**（api/local/off 三态自动）与 `_pack/_unpack`（float32 LE BLOB）；检索 numpy 全表余弦（千条量级毫秒级）；
- **embedding off 模式**：relevance 信号缺失 → 三信号退化为 recency + importance 双信号（权重重归一化）+ FTS5 关键词通道兜底；检索元数据如实标 `embed=off`（与 DocIR 的 off 降级同口径，不冒充）。

### 2.11 worker 配置
- `settings.memory_worker_interval_s`（默认 600，`<=0` 关闭，仿 `tracking_interval_s`）；单测 env 覆盖为 0；
- 简报缓存：per-conversation 内存 dict + SQLite 落盘（重启续用），worker 周期刷新 + 新证据（新入库论文相似块 / tracked_items 新条目 / 新 experiment_result 记忆）到达时主动失效。

### 2.12 理论 ↔ 实现映射（论述增强，答辩可直接引用）
| 陈述中的理论 | 本项目实现 | 代码位置 |
|---|---|---|
