🆕 v2 新增层

记忆与状态层Time-Aware Memory · 事件流 / 时间图谱 / 状态机 三层分离

理论依据：THEANINE（NAACL 2025）时间线记忆图谱 · Generative Agents（UIST 2023）三信号检索 · FadeMem（arXiv 预印本）遗忘曲线 · Memory-T1 精筛思想 · MemGPT self-editing · 假设状态机与记忆分离（记忆=发生过什么，状态=现在处于什么）
🆕 记忆事件流——memory_events（append-only 只增不删 · t_valid 时间有效期 · (event, time) 二元组） 🆕 时间知识图谱——entities 实体消解 + memory_edges 因果/时序边（refutes / supersedes / supports / cause…；P0 规则建边 → P1 LLM 升级，规则边保留；过期标 superseded 不删除） 🆕 假设生命周期 FSM——proposed→active→supported/refuted/superseded（合法转移表强制；与记忆层、LangGraph 任务层三态分清） 🆕 记忆检索器——三信号 recency+importance+relevance（min-max 归一化等权相加）× FadeMem 强度 × 时间窗（timeparse：自然语言→区间）→ 多跳 BFS≤2 → 线性时间线路径 🆕 研究简报——假设 vs 新证据 judge → memory_brief SSE 开场下发；无证据标 unverified 不冒充 🆕 巩固 worker——FadeMem 双层软衰减（LML β=0.8 / SML β=1.2 · 滞回 0.7/0.3 · 只降排序不物理删除）+ 周期假设复核（仿 tracker 水位线）

证据与校验层Evidence-First · 抗幻觉核心 · 本层不动
