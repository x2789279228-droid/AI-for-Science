# 最终落地架构与选型变化说明（2026-11-15）

> 11/7 参赛方案（`传智杯-AI科研助手-完整参赛方案.md`）写于编码开始前，基础设施选型为
> 「Qdrant + Postgres + Redis + Langfuse 等 7 容器」。本文说明**实际落地形态**与收敛理由，
> 供评审对照——两份文档不一致处，以本文与代码为准。

## 一、落地形态：2 容器单机栈

```
┌─ docker compose ──────────────────────────────┐
│  api   (python:3.12-slim + uv)   :8100        │
│    FastAPI + LangGraph 状态机                  │
│    SQLite(WAL)：scholar.db + checkpoints.db   │
│    chunks_fts5(中文 bigram) + vec BLOB 向量列  │
│  web   (node:20-alpine, next start) :3000     │
│    Next.js 14 · 浏览器直连 :8100（SSE）        │
│  volumes: ./data（演示快照恢复源 data-real）   │
│           ./docs/acceptance(ro，外部校准数据源)│
└───────────────────────────────────────────────┘
```

## 二、逐项选型变化与理由

| 老方案 | 落地 | 收敛理由（单人 + 省赛演示约束下的诚实取舍） |
|---|---|---|
| Qdrant 向量库 | SQLite `chunks.vec` BLOB 列 + 暴力余弦 | 语料 20 篇 / 3.2k chunk，量级差 3 个数量级；省一次跨容器网络往返；检索质量由 **RRF 混合（BM25 中文 bigram + dense）+ bge-reranker 精排** 保证（消融 Wilcoxon p=0.0002），而非向量库本身；dense 向量缺失的静默损伤已收敛为健康指标 `dense_vec_coverage`（当前 100%）+ 幂等回填脚本 |
| Postgres | SQLite WAL（`busy_timeout=30s`，每调用独立连接） | 单机单进程写型负载；WAL 下读写并发实测满足演示档；换库成本集中在 `db.py` 一个模块 |
| Redis（缓存/限流） | 进程内 TTLCache（数据修订版号失效）+ 令牌桶限流 | 缓存需与数据修订联动（`X-Data-Revision`），进程内实现反而更精确；单机口径限流已如实注明「非多租户鉴权」 |
| Langfuse（LLM 可观测） | 自建审计链：`qa_logs`（每次调用 token/时延/prompt 版本/guardrail）+ `trace_events`（节点级事件流落盘）+ `/audit` 透明度中心 | 可观测需求 = 审计与回放，自建表结构与前端回放页强耦合，第三方面板反而多一跳；支持 `--replay` 式复核（sha256 证据 manifest） |
| MinerU 容器 | 宿主机增强通道（镜像内 `MINERU_ENABLED=off`，PyMuPDF + 扫描件 VLM 兜底） | torch 镜像体积；解析路由 probe→native/scanned/gray/long 已按引擎可用性自动降级，功能不缺位 |
| 7 容器 | 2 容器 | 演示启动时间（`make demo` 一条命令）、4C8G 云主机内存预算、故障面收敛；compose 结构保留横向扩展位（加服务不改网络拓扑） |

## 三、没有变的部分

- LangGraph 显式状态机编排（主图 14 节点 + Executor Send 扇出子图，见 `docs/agent-graph.md`）；
- 四层抗幻觉防线（混合检索→Evidence Pack→[E#] 强制引用→L1-L4 Claim 校验，judge 双 κ 校准）；
- 全部业务功能矩阵（解析/问答/翻译/去重/图谱/写作/推荐/追踪）——老方案的功能承诺逐一兑现，只换了承载它们的基础设施。

## 四、在线部署注意（评审可访问形态）

- 反代（Nginx/Caddy）必须对 `/api/chat` 等 SSE 端点**关闭缓冲**（`X-Accel-Buffering: no` 已由服务端下发；Nginx 需 `proxy_buffering off`）；
- 端口约定：容器内 3000/8100（compose `3000:3000`）；本机开发 dev 跑 3005、本机生产跑 3003（避开本机 3000 占用）——对外统一暴露 3000；
- `.env`（LLM/embedding key）不入镜像不入库（gitignore 覆盖，git 历史无泄漏）；离线无 key 时抽取式降级闭环仍可演示。
